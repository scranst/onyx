# Welcome to Onyx

Onyx is a local-first markdown notebook. A **vault** is just a folder of plain
`.md` files that you own — no database, no account.

## Getting started

- Press `Ctrl+P` for the command palette.
- Press `Ctrl+E` to flip between editing and reading view.
- Press `Ctrl+Shift+F` to search every note in the vault.

## Wiki links

Link notes together with double brackets: [[Ideas]].

> [!tip] Callouts
> Blockquotes beginning with `[!tip]` render as callouts, like the original.
